[JSIA-A09]

Crie um pequeno programa em JavaScript que simule um sistema simples de notas escolares.

Seu código deve:

1. Declarar um objeto `aluno` com as seguintes propriedades:
   - `nome` (string)
   - `idade` (number)
   - `notas` (array de 3 números)

2. Possuir um método `calcularMedia()` que retorna a média das notas.

3. Utilizar desestruturação para acessar `nome` e `idade`.

4. Usar o **spread operator** para adicionar uma nova nota ao array original.

5. Criar uma função chamada `verificarSituacao` que:
   - Receba a média como parâmetro.
   - Verifique se o aluno está **aprovado** (média ≥ 7) ou **reprovado**.
   - Retorne uma mensagem adequada.

6. Utilizar um **loop** para exibir todas as notas no console.

O programa deve exibir no console:
- Nome e idade do aluno
- Todas as notas
- A média final
- A situação (aprovado ou reprovado)
